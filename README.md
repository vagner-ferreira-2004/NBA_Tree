# 🏀 NBA_Tree

## 📌 About the Project

**NBA_Tree** is a project developed to apply **Data Structures** concepts using a **Binary Tree** to organize and manage NBA-related information.

The project demonstrates how a tree structure can be used to store, search, and organize data efficiently.

## 🎯 Project Objective

The main objective is to provide a practical application of **Binary Tree** concepts, connecting theoretical knowledge from Data Structures with information related to the NBA.

## ⚙️ Main Operations

* Insert data into the tree
* Search for elements
* Remove elements
* Traverse the tree
* Organize data hierarchically
* Apply Binary Tree concepts in practice
